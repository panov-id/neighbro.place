# neighbro.place
NEIGHBRO — глобальное лицо гиперлокальной соседской сети. Знакомься с людьми в своём доме, офисе или квартале по совпадению настроения и интересов, а не бесконечным свайпам. Когда два соседа кликают друг с другом, открывается лёгкий live-чат — а дальше уже вы сами решаете, куда это ведёт. Только фронтенд — одно из двух лиц, работающих на общем бэкенде.

## Ссылки

- [`xor.ad`](https://github.com/panov-id/xor.ad) — общая платформа за этим фронтендом; полное описание концепции, архитектуры и политики модерации там.
- [`sosed.place`](https://github.com/panov-id/sosed.place) — русскоязычное/СНГ родственное лицо.
