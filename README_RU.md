# neighbro.place
NEIGHBRO — одно из двух лиц гиперлокальной соседской сети. Знакомься с людьми в своём доме, офисе или квартале по совпадению настроения и интересов, а не бесконечным свайпам. Когда два соседа кликают друг с другом, открывается лёгкий live-чат, а соседи рядом публикуют бесплатные локальные офферы. Только фронтенд — оба лица работают на общем бэкенде.

## Ссылки

- [`xor.ad`](https://github.com/panov-id/xor.ad) — общая платформа за этим фронтендом; полное описание концепции, архитектуры и политики модерации там.
- [`sosed.place`](https://github.com/panov-id/sosed.place) — родственное лицо на том же бэкенде.

## Поддержать

Сервис не берёт денег: офферы размещаются бесплатно, внутреннего баланса нет. Инфраструктуру покрывают добровольные донаты.
