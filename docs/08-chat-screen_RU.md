# Экран 8 — Чат

## Назначение

Экран приватной переписки между двумя заматчившимися пользователями.

## Элементы экрана

- Лента сообщений переписки — короткие сообщения туда-сюда.
- Уведомления о новых лайках между этими двумя пользователями появляются прямо в этой ленте (см. экран 6).
- Поле ввода и отправки сообщения.

## Логика

- История переписки существует только между этими двумя участниками — больше нигде.
- В отличие от сообщений в ленте, переписка не исчезает через 4 часа 20 минут — живёт дольше, пока чат открыт.
- Переписка не проверяется модерацией. Ни токсичность, ни откровенность: текст беседы не уходит ни в Perspective, ни в языковую модель и не покидает пары устройств. Проверяется только то, что публикуется в ленту (см. `00-mechanics_RU.md`, §5).
- Переписка шифруется **на устройствах**: ключ выводится у собеседников и на сервер не попадает, узел переносит шифротекст (см. `xor.ad/docs/chat_RU.md` §8.13). То есть беседа не только не проверяется — её и прочитать нечем.
- История хранится на устройстве в IndexedDB, зашифрованная через Web Crypto API перед записью (см. раздел «Приватность» в README) — а не в каком-то отдельном "защищённом" хранилище браузера, такого не существует.

## Открытые вопросы

- Что именно означает "пока чат открыт" — есть ли способ закрыть/удалить чат вручную, и что тогда происходит с историей.
- Индикаторы прочтения/статус доставки не определены.
