# neighbro.place
NEIGHBRO — one of two faces of a hyperlocal neighbour network. Meet people in your building, office, or block by matching on shared vibes and interests, not endless swiping. When two neighbours click, a light live chat opens, and neighbours post free local offers. Frontend only — both faces share a single backend.

## Links

- [`xor.ad`](https://github.com/panov-id/xor.ad) — the shared platform behind this frontend; full concept, architecture, and moderation policy live there.
- [`sosed.place`](https://github.com/panov-id/sosed.place) — the sibling face, on the same backend.
